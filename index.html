第一次连接 Mac

  1. 在 Mac 上打开“系统设置 › 通用 › 共享”，打开“屏幕共享”。
  2. 在 Ferry 里轻点“+”，填 Mac 的地址（例如 192.168.1.20 或 我的Mac.local），同一网络里的 Mac 也会出现在“附近”。
  3. 用这台 Mac 的登录用户名和密码连接。

常见问题

  • 连不上：确认电脑开着屏幕共享（或 VNC 服务）、地址和端口（默认 5900）正确，防火墙允许连接。不在同一网络时，需要在路由器上设置端口映射，或在 Ferry 里打开 SSH 连接。
  • 高性能和虚拟显示器：需要 Apple 芯片的 Mac 和 macOS 14 或更新版本，并用 Mac 的登录账户连接；其他电脑照常普通连接。
  • “允许粘贴”提示：同步剪贴板时 iOS 会询问是否允许读取其他 App 的内容，可以在“设置 › Ferry › 从其他 App 粘贴”里选“允许”。
  • Windows 和 Linux：可以连接任何标准 VNC 服务器。

Connecting to a Mac for the first time

  1. On the Mac, open System Settings › General › Sharing and turn on Screen Sharing.
  2. In Ferry, tap + and enter the Mac's address (for example 192.168.1.20 or My-Mac.local). Macs on the same network also appear under Nearby.
  3. Connect with the Mac's login user name and password.

Common questions

  • Can't connect: make sure Screen Sharing (or a VNC server) is on, the address and port (5900 by default) are right, and the firewall allows the connection. From another network, set up port forwarding on your router or turn on SSH in Ferry.
  • High performance and virtual displays: require a Mac with Apple silicon running macOS 14 or later, signed in with a Mac user account. Other computers connect normally.
  • "Allow Paste" prompt: iOS asks before Ferry reads content copied in other apps. Choose Allow in Settings › Ferry › Paste from Other Apps.
  • Windows and Linux: Ferry works with any standard VNC server.

第一次連線 Mac

  1. 在 Mac 上打開「系統設定 › 一般 › 共享」，開啟「螢幕共享」。
  2. 在 Ferry 中點一下「+」，輸入 Mac 的位址（例如 192.168.1.20 或 我的Mac.local），同一網路中的 Mac 也會出現在「附近」。
  3. 用這部 Mac 的登入使用者名稱和密碼連線。

常見問題

  • 連不上：確認電腦已開啟螢幕共享（或 VNC 服務）、位址和連接埠（預設 5900）正確，防火牆允許連線。不在同一網路時，需要在路由器上設定連接埠轉送，或在 Ferry 中開啟 SSH 連線。
  • 高效能和虛擬顯示器：需要 Apple 晶片的 Mac 和 macOS 14 或以上版本，並用 Mac 的登入帳號連線；其他電腦照常一般連線。
  • 「允許貼上」提示：同步剪貼簿時 iOS 會詢問是否允許讀取其他 App 的內容，可以在「設定 › Ferry › 從其他 App 貼上」中選「允許」。
  • Windows 和 Linux：可以連線任何標準 VNC 伺服器。

はじめて Mac に接続するには

  1. Mac で「システム設定 › 一般 › 共有」を開き、「画面共有」をオンにします。
  2. Ferry で「+」をタップし、Mac のアドレス（例：192.168.1.20、My-Mac.local）を入力します。同じネットワーク上の Mac は「近く」にも表示されます。
  3. その Mac のログインユーザ名とパスワードで接続します。

よくある質問

  • 接続できない：画面共有（または VNC サーバ）がオンになっているか、アドレスとポート（既定は 5900）が正しいか、ファイアウォールで許可されているかを確認してください。別のネットワークからは、ルータでポート転送を設定するか、Ferry で SSH をオンにしてください。
  • 高パフォーマンスと仮想ディスプレイ：Apple シリコン搭載で macOS 14 以降の Mac に、Mac のユーザアカウントで接続する必要があります。そのほかのコンピュータには通常どおり接続できます。
  • 「ペーストを許可」の確認：ほかの App でコピーした内容を読み取る前に iOS が確認します。「設定 › Ferry › ほかの App からペースト」で「許可」を選べます。
  • Windows と Linux：標準的な VNC サーバであれば接続できます。
